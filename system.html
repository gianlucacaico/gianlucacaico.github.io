Use it anywhere

One line

The kit is one stylesheet hosted on this site. Paste it into any page or prototype that takes HTML and it picks up this look.

  1. 1

    Add the look

    Paste this line inside the page's head. Colours, type, buttons, glass and cards come with it.

    <link rel="stylesheet" href="https://gianlucacaico.com/kit/gc.css">
  2. 2

    Add the interactions

    Only needed for segmented controls. Everything else works without it.

    <script src="https://gianlucacaico.com/kit/gc.js" defer></script>
  3. 3

    Make it yours

    Your playground settings, ready to paste after the first line.

    <style>
  :root{
    --accent:#635BFF;
    --accent-deep:#4B44D6;
    --accent-2:#EB5D76;
    --round:1;
    --glass-blur:20px;
  }
</style>
  4. 4

    Copy the components you need

    Every component in the demo has its code underneath, ready to paste.

    Open the demo
